## v1.0.0-pockigo-pomodoro - 2026-10-16

First release of the PockiGo baseline, built for the ESP32-S3R8 handheld.

- **New product baseline.** One board profile: ESP32-S3R8 with 16 MB Flash and
  8 MB Octal PSRAM, a 240 × 320 ST7789 display, six discrete GPIO keys (UP, DOWN,
  A, B, LEFT, RIGHT — no separate OK key), a direct I2S amplifier output with no
  codec, and battery voltage estimated from a 200K/200K divider on GPIO1. The
  board has no I2C devices.
- **Renamed artifacts.** The CMake project and every published file are now
  `PockiGo`: the merged flashable image is `build/PockiGo-full.bin` and the debug
  archive keeps `PockiGo.elf` / `PockiGo.map`. Flash the merged image from `0x0`.
  The previous `Pocket-Creator-full.bin` name is gone.
- **Application.** `main` builds the Pomodoro application (build tag `1.0.0-s3`)
  with its own RGB565 canvas renderer and Chinese glyph table. The older
  hardware-test pages (`demo_*.c`, `ui_pixel.*`) stay in the tree but are not
  compiled; new applications must implement their own UI.
- **Rendering-path policy.** Ordinary applications should use LVGL through
  `espressif/esp_lvgl_port`; only a high-refresh-rate full-screen renderer, such
  as the Chick Run game, should draw directly with `esp_lcd_panel_draw_bitmap()`.
  Both paths share the same BSP display APIs and the rounded-corner mask helpers.
- **Removed the retired ESP32-C3 profile.** Its codec and fuel-gauge code, its
  low-power/battery demos, its host-test stubs, and its firmware-verification
  tables (8 MB Flash, `esp32c3` chip identity, RISC-V ELF) were deleted. Firmware
  verification now accepts only the 16 MB ESP32-S3 image.
- **Documentation.** Every maintained document ships as an English/Chinese pair.
  The product specifications, hardware guide, and capability tables now describe
  the ESP32-S3 hardware only, and the README homepages carry the PockiGo wordmark
  (transparent background cropped to the artwork) linked to
  <https://pocket.takecloud.cn>.
- **Validation.** `./tools/validate.sh` runs repository checks, host tests, a
  firmware build, and merged-image verification; pushing a `v*` tag builds the
  firmware and publishes `PockiGo-full.bin` as a release.
